# Phase 5F L2 Hostility trait matrix

This directory contains the dedicated 39-trait runtime-coverage evidence that
follows Suite B. It does not contain a Phase 6 implementation or a balance
change.

The development-only `Phase5FL2TraitMatrix` harness has three isolated modes:

- `catalog` reads the live L2 Hostility dynamic trait registry and datapack
  legality metadata.
- `natural` attaches each accepted Tensura/NEB boss at the exact requested
  levels 50, 100, 150, 200, 300, 400, 500, 600, 800, and 1000. Values outside
  an entity's configured range use the same temporary requested-level fixture
  established in Phase 5F and remain explicitly labeled.
- `forced` suppresses generated traits, attaches one exact trait/rank, and
  exercises real Royal Bow/Royal Arrow physical hits, a direct-physical control,
  Magic Weapon Native, the locked temporary S7 coefficient fixture, boss
  offence, healing, equipment, movement, spawning, and lethal-transition probes.

Forced rows are always compatibility evidence only. A naturally legal trait
is labeled `FORCED_DIAGNOSTIC`; an entity-illegal trait is labeled
`FORCED_ILLEGAL_DIAGNOSTIC`. Neither may be used as natural-spawn or balance
evidence. The harness is registered only in the non-production development
environment, and every artifact records `APO_profile = NONE` and
`production_combat_mutated = false`.

`scripts/extract-phase5f-l2-traits.ps1` is the acceptance gate. It requires the
exact 39-trait catalog, exact requested levels/ranks, clean terminal result,
zero case errors, correct evidence labels, no production mutation, and no
unexpected L2 bypass before preserving JSONL. Raw runtime logs remain ignored.

Validated evidence will be added under `natural/`, `forced/`, and `profiles/`.
The terminal one-row-per-trait classifications will be stored in
`coverage.jsonl` after cross-trait validation.

## Legal / natural matrix result

All seven accepted bosses completed the exact ten-level ladder: 70 profiles,
zero case errors, zero requested/attached level mismatches, 39 legality rows per
profile, `APO_profile = NONE`, and the Tensura:L2Hostility scaling marker on
every profile. Levels outside each boss's datapack range are explicitly marked
`SAFE_REQUESTED_LEVEL_OVERRIDE`; no level was silently substituted.

Native generation produced 26 distinct traits. Tank, Speedy, Regenerate, and
Reflect reached their full native rank 5; the ordinary rank-3 traits that
appeared also reached rank 3; Ragnarok naturally appeared at ranks 1-2. The 13
traits not generated by these 70 finite RNG profiles were Arena plus the 12
traits rejected for all seven SEMIBOSS entities by their runtime restrictions:
Counter Strike, Grenade, Growth, Invisible, Master, Protection, Pulling,
Repelling, Shulker, Split, Teleport, and Undying. Absence from generation is
not treated as behavior coverage; those traits remain for forced diagnostics.

The configured global/effective `maxTraitCount` was 9. Fourteen profiles
reported 10-12 final traits because entity preset traits are inserted before
the random-pool stopping condition; this is observed native generator behavior,
not a harness-created illegal stack. L2 does not retain the effective
`trait_cost` factor or remaining budget after generation, so those two values
are explicitly `NOT_RUNTIME_OBSERVABLE`. Each profile retains the nominal
non-free raw-cost upper bound for audit without mislabeling it as consumed
budget.

## Forced diagnostic matrix result

The isolated Luminous diagnostic completed all 110 native rank cases across
the exact 39-trait catalog with zero case errors. Every row used the real Royal
Bow and Royal Arrow, disabled Royal Arrow Mark, kept `APO_profile = NONE`, and
ran physical-arrow repeats, direct physical control, Magic Weapon Native, the
temporary S7 coefficient fixture, boss-sourced offence, and the relevant
movement/equipment/healing/death probes. A nearby Armor Stand records aura and
movement behavior; a separate deinitialized, equipped Zombie receives the
controlled boss-sourced hits so the probe cannot contribute its own L2 traits.

The artifact preserves live legality per row: 27 traits are legal for the
tested SEMIBOSS and 12 are explicitly `FORCED_ILLEGAL_DIAGNOSTIC`. These are
compatibility observations only. The strict extractor found no unexpected L2
bypass. Terminal one-row-per-trait conclusions and the additional legal
worst-case profile work remain pending and are not implied by this checkpoint.
