### Minoshroom melee

Priority3 native MeleeAttackGoal(speed1,false) uses live target, path or melee reach, native LOS and melee AABB. Requires every-tick update; attack counter decremented then tested, resets20 before dispatch, independent of hurt success. It calls Minoshroom.doHurtTarget, which REPLACES ordinary Mob.doHurtTarget with EntityUtil.properlyApplyCustomDamageSource using twilightforest:axing, direct=causing=Minoshroom. Effective attack attribute passes native EnchantmentHelper.modifyDamage before victim.hurt, but the helper supplies ATTACKER itself as the affected Entity argument instead of victim (unlike Mob.doHurtTarget); target-dependent enchantment evaluation therefore uses that wrong entity context. True enables enchantment-adjusted ATTACK_KNOCKBACK*0.5, attacker XZ velocity*0.6 when extra knockback>0, and native post-attack enchantments. Helper mistakenly calls setLastHurtMob(attacker itself), not victim; preserve this installed distinction. False suppresses those success callbacks; true need not mean HP loss. It is a vanilla-like extended melee package, not an invented ordinary mob_attack CUSTOM_DAMAGE. Axing is physical-tagged with normal armor/Resistance/protection/absorption/cooldown.
