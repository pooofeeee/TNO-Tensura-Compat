### Scheduler, projectiles and vanilla primitives

`Goal.requiresUpdateEveryTick` defaults false. `Mob.serverAiStep`, `GoalSelector` and `WrappedGoal` establish the ordinary alternating scheduler: these goals normally tick once per two server ticks; entity counters continue each entity tick. Do not convert a goal countdown directly to the same number of server ticks. Guardian combo damage offsets and cooldowns must use the actual start/super/tick order. For an uninterrupted Manipulator conversion, goal start assigns 35, the same full goal tick sees 35, and the entity's post-super tick decrements to 34. Following full goal ticks see 33,31,...,1; the conversion branch at 1 is reachable, normally 34 server ticks after start. Interruption/disabled AI can alter this schedule. Native invocation, not manual goal calls, is the future control.
