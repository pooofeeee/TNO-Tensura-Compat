## طريقة التحقق عند الاستئناف

- افتح رابط المجلد وافحص بيانات النسخة عند اختلافها؛ ثبّت الفصل ومعرف الفقرة الموجود في الصفحة.
- روابط #line_N مثبتات إلكترونية في النسخة المشاهدة. إذا تغيرت النسخة، لا تفترض بقاء ترقيمها؛ سجل التغير وقارن السياق.
- لا تطابق تلقائي بين F11 ونسخة Slime Reader لمجرد تشابه أسماء المترجمين.
- القديم معتمد بحدوده المسجلة، لا بوصفه شاهدًا جديدًا أو تدقيقًا يابانيًا.
