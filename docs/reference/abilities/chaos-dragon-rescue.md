# قدرات إنقاذ Chaos Dragon — حالة مشتركة

## V10-C5-RESCUE

SR10، فصل 5، [line_5163–5270](https://tensurafan.github.io/read/v10#line_5163)، ترجمة DasRay/Anna، الطبعة 7، مارس 2023. أسماء القدرة كما في هذه النسخة، ومنها صيغة الهتاف Drago Bustaaa؛ لا يُثبت هذا تهجئة معيارية مستقلة، ولم تُطابق الأسماء باليابانية.

| صاحب/فعل | الدليل والشروط في الحالة |
|---|---|
| Milim: كبح ثم Drago Bustaaa / Drago Nova | القوة وحدها لا تحقق حفظ الصديق؛ تخشى إصابة النواة، وتزيد الدفع بتنسيق ريمورو |
| Raphael/ريمورو: التحليل والتنسيق | يساعد التحليل في التحكم؛ يذكر ريمورو تناقص ماجيكوله. لا نسبة استهلاك معلومة |
| Beelzebuth / Devour Soul | التقاط النواة المكسورة قبل تدميرها بالتزامن مع إزالة الجسمين الروحي والنجمي؛ النجاح هنا مع رؤية وتوقيت محددين، لا مدى/سرعة كونيان |
| معالجة الأثر المتبقي | توقف سحر مليم لا يزيل الطاقة الكثيفة؛ يلتهمها Beelzebuth بعد حساب رافائيل |
| حالة الروح | انظر [سجل Gaia](../world/gaia-core.md)؛ التقاط النواة ليس وحده اكتمال الإحياء |

**حدود:** لا اسم نوع طاقة نهائي مستنتج من وصف الضوء أو lightning؛ ولا تصنيف كل هجوم لمليم أو قدرات تحولها. لا تثبت الحالة أن الطرفين يمكنهما إعادة العملية على كل روح أو تنين. اختفاء ضباب Greed تزامن مع تطور الحدث؛ تفسير ريمورو له بموت ماريابيل لا يتحول وحده إلى قانون انتهاء كل تأثير عند موت المستخدم.

**جاهزية التنفيذ:** علاقات سببية جزئية بين الهجوم الدقيق، كشف النواة، الالتقاط ومعالجة الخطر؛ ليست مواصفات نظام قتال أو إحياء مكتمل. تبقى شروط الاستهداف والموارد والحدود المكانية والتعارضات وفشل العملية مفتوحة.
