# Chosen One — مرحلة ماسايوكي في LN9–10

## V9-M-CHOICE

SR09: إنجليزية، DasRay/Anna، الطبعة 3، مارس 2023؛ بيانات النسخة والنص قُرئا مباشرة. [Prologue، line_160–182](https://tensurafan.github.io/read/v9#line_160)، 231–242؛ الفصل 4، 2943–3033 و3125–3148. لا مقارنة يابانية.

| الحقل | الدليل المحدود |
|---|---|
| الوظائف المسماة | Hero’s Haki وHero’s Blessing وHero’s Charisma وHeroic Action؛ اختلاف تسميات Heroic Act/Spirit في النسخة لا يثبت مهارات مستقلة |
| آلية وصفية | هالة تقيد الأضعف، حظ وضربات حرجة للمستخدم والرفاق، تشجيع المتفرجين وإعادة تفسير أفعاله إيجابيًا |
| الأتباع | يصف Hero’s Charisma انضمام المهزوم الحي حتى من المخلوقات العاقلة؛ هذه وظيفة موصوفة، ولم تُختبر حدود جميع الأهداف هنا |
| سيطرة المستخدم | يصفه السرد بأنه passive؛ لا يتوقف لمجرد تمنيه ذلك |
| شاهد نجاح | نتيجة مواجهة Jinrai وتفسير الجمهور؛ لا مهارة سيف خفية مستنتجة من المديح |
| شاهد قيد | ينسحب أمام Gobta؛ يستمر التفسير الإيجابي للجمهور. الانسحاب ليس إبطالًا تقنيًا للمهارة |
| مقارنة ريمورو | رافائيل يقول إن معظم المهارات الأدنى تتعطل أمام Ultimate؛ هذا ليس «كل Unique يفشل دائمًا» |
| تكلفة/مدى | الكميات والمدة وحدود عدد الرفاق/الجمهور غير محددة هنا |

**تمييز لازم:** القوة الشخصية، تعزيز الرفاق، تشكيل الانطباع، وإرادة المستخدم ليست قيمة واحدة. عبارة السرد المقارنة بقوة Ultimate لا تغير التصنيف المعلن Unique ولا تثبت نتيجة كل مواجهة.

**مجهول:** تعريف الطرف/الرفيق، حدود إرغام المهزومين، مقاومات كل وظيفة، العزل والتعطيل والتطور اللاحق. لا تُدخل نسخ ماسايوكي المستقبلية أو هوية أخرى في هذه المرحلة.
