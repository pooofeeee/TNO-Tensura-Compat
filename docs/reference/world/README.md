# خريطة قوانين العالم

مدخل مرحلي للأنظمة، لا أنطولوجيا مكتملة. استمرارية LN فقط في السجلات الحالية.

| الفصل المطلوب | الأدلة الحالية | الفجوات |
|---|---|---|
| [الأجسام والوجود والتجسد](embodiment.md) | حالات بيريتا وديابلو وإفريت وشياطين LN11 | هوية المصطلحات اليابانية والحدود العامة |
| الطاقة والماجيكول | حقول موارد داخل سجلات التجسد والقدرات | الإنتاج/الانتقال/الفقد/التعافي والمقاييس |
| المهارات والفنون والسحر | Greed وSniper و[حالة السحر المقدس](holy-magic-cases.md) والجرد المرحلي | شروط الاكتساب والتفعيل والتداخل والتطور |
| الإدراك والمعرفة | سجلات الشخصيات مرتبطة بالمشاهد | حدود كل حاسة/تحليل ووسائل الخداع |
| التسمية والتطور | إحالات LN5 وLN11 | قانون شامل وموانع واستثناءات |
| الروح والهوية والموت والإحياء | أدلة متفرقة محفوظة | تعريفات ومراحل وفشل وشروط |
| المكان والزمان والمعلومات | قدرة واحدة جزئية وتصريح استخدام | لا خريطة نظام حتى الآن |
| المقاومات والدفاع والهجوم والشفاء | قيود بعض المشاهد | المقارنة بين آليات محددة |
| المواد والبيئة والمجتمع والصناعة | غير ممسوحة كنظام | تُضاف حسب النصوص ومخطط الاعتماد |

كل فصل جديد يحتاج أمثلة متوافقة ومخالفة وسياقاتها. لا يُشتق قانون كوني من اصطلاح ترجمة أو تصنيف مود. يمكن للمنفذ استعمال العلاقات المثبتة داخل نطاقها فقط؛ الأرقام والسلوكيات غير المغطاة تبقى قرارات تصميم معلقة.

## إضافات مترابطة

- [حالة السيطرة والإكراه](control-cases.md): الفصل بين القيد وشهادة الخوف وتشخيص تأثير الرغبة.
- [إنقاذ النواة](../abilities/chaos-dragon-rescue.md): الهجوم والتحليل والالتقاط ومعالجة الطاقة في تعاون محدد.
- [Gaia](gaia-core.md): فصل تجهيز الوعاء عن تعافي الجسد المتوقع. لا قانون إحياء عام.


## فهرس مرحلة محددة لا قانون أسماء

[جرد ريمورو LN5](../abilities/rimuru-ln5-inventory.md) يفصل الاكتساب عن الدمج وعن الوظائف التابعة. أسماء مثل Universal/Absolute ليست وحدها اختبارًا للمقاومات؛ [شاهد الدفاع LN7](../abilities/hinata-ln7.md) محفوظ بتوقيته وشروطه.

## إضافات REF-25/26/27

[مواجهة مليم في LN6](../abilities/milim-walpurgis.md) تربط التشخيص وحدود المعرفة بالفعل والموارد؛ لا تجعل التفسير الأول تقريرًا تقنيًا من رافائيل. [حالة السحر المقدس](holy-magic-cases.md) مدخل جزئي لفصل السحر؛ لا قانون إيمان شامل أو جرد لقدرات مليم.
