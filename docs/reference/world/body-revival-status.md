# مراجعة تغطية: الجسد والموارد والإحياء

**REF-84-S، تجميع تحليلي فقط، 2026-10-30.** يعيد استعمال السجلات المرتبطة، ولا يضيف شاهد رواية مستقلًا أو يعلن اكتمال الأنظمة. «مجاب ضمن الحالات» لا تعني قاعدة لجميع كائنات Tensura أو جميع مراحل الشخصية.

## أسئلة أصبح لها جواب مقيد بالمصدر

| السؤال | ما تدعمه الحالات المقروءة | الدليل/الحد |
|---|---|---|
| هل الاستدعاء والجسد والوعاء والعقد والتسمية خطوة واحدة؟ | لا تدمج؛ يختلف ترتيبها وموردها بين Beretta وDiablo وإفريت والثلاثي | [أدلة التجسد](../../TNO_EMBODIMENT_EVIDENCE.md)، [مصفوفة التسمية](naming-cases.md)؛ لا وصفة كونية |
| هل ذكر مورد يكفي لتسعير كل عملية؟ | موارد حفظ جسم مؤقت، تسمية، إحياء LN5، بناء/بيئة المتاهة حقول منفصلة | [التجسد](embodiment.md)، [LN5](resurrection-ln5.md)، [LN8](ramiris-labyrinth-ln8.md)؛ لا سعر موحد |
| كيف يعمل مسار السحر المقدس الموصوف؟ | معرفة/إنشاد وعلاقة بالمتحكم في spiritrons، مع إعارة mana ومعالجة في شرح LN10 | [قناة الإيمان](holy-faith-ln10.md)، [تطبيق ديابلو](diablo-raine-ln11.md)؛ اعتراف Shuna بالمحاكاة يراجع تفسير قولها السابق |
| ما الذي صُنع في تجربة الـavatar؟ | حاوية محاكية وكور وجسم بقدرات محدودة ثم ارتباط/ملكية وخروج؛ ليست صناعة روح كاملة | [LN10 REF69–72](avatar-ln10.md)؛ لا كل قدرات الأصل أو سلامته من كل ضرر |
| هل الإحياء في المتاهة متاح لكل شيء بلا شرط؟ | مسارات إدارة/تابع/أداة/طوق، مع شاهد مضاد لغولم بلا إرادة وقيد وعي Ramiris | [LN8 REF77–79](ramiris-labyrinth-ln8.md)؛ لا تساوٍ بين كل مسارات الأهلية |
| هل سوار LN9 يحيي من مات خارجها أو يمنع الألم؟ | الشرح يقيد الوفاة بالداخل، والعرض يظهر ألمًا وعودة جسدية؛ صلاحية موظف قيدت وظيفة محددة | [LN9 REF73–76](labyrinth-revival-ln9.md)؛ ليس محو كل ألم/إثبات كل ذاكرة |
| هل وجهة العودة وعدد الطوابق ثابتان أبديًا؟ | سطح LN9، نقاط تابع LN8، وتصريح وجهة30 وطابق101 مؤقت LN13 حالات مختلفة | [LN13 REF81–83](labyrinth-war-ln13.md)؛ لا وجهة حرة لكل مستخدم أو توسع لانهائي |
| هل الطاقة البيئية هي كلفة الإحياء؟ | مصدر Veldora للبيئة موثق، والربط بميزانية الإحياء لم يثبت | [LN8](ramiris-labyrinth-ln8.md) و[LN13](labyrinth-war-ln13.md)؛ فصل مثبت في البحث، لا نفي لاحتمال علاقة غير مشروحة |

## أسئلة ما زالت تنتظر نصًا محددًا

| الفجوة | الدليل المطلوب للحسم | ما لا يحسمها |
|---|---|---|
| مورد الإحياء وكلفته وسعته/تزامنه | تصريح مصرف/تحمل أو واقعة نجاح/فشل مرتبطة صراحة بالحمل وشروطه | حجم الجيش، ambient magicules، بيع الأساور أو وصف الخلود وحده |
| سلامة أصل الـavatar | مشهد أو شرح يحدد أثر إصابة الأصل/الوسيط أو الموت/قطع الاتصال على الطرف الآخر | نجاح Possess/Exit أو إحياء تابع في المتاهة |
| الروح المفقودة/الممحوة والهوية | نص يميز الضرر والمحو والأسر وحدود الاسترجاع والذاكرة في الحالة نفسها | core مثقوب، جسد أصلح، أو اسم قدرة ذاكرة فقط |
| غياب/قتل Ramiris أو قطع الإدارة | وصف صريح لاستمرار/انقطاع القدرة ومصير الموجودين | قول اختفائها عند قتلها أو وجود خطة إخلاء |
| تقييد/إنهاء قناة الإيمان | شروط منح/سحب/مقاومة ومدى وموارد صاحب السلطة | نجاح تعويذة أو عدد المؤمنين دون علاقة كمية |
| ألفاظ التجسد/نقل الأشياء | نص ياباني مطابق أو توضيح LN مستقل منطبق | إصلاح physical presence أو نفي LN8 L329 بالحدس |
| أهلية استيقاظ ريمورو السابقة | تصريح سببي عن منشئها | تعاقب ابتلاع Geld ثم الاستيقاظ لاحقًا |
| تعافي Gaia بعد تجهيز الكور | ظهور/شرح يثبت النتيجة ومراحلها | توقع LN10 فصل5 بأن النواة ستتعافى ويتشكل الجسد |

هذه فجوات معرفة أو وصول مختلفة: F03 منع قراءة، F02 P254 نص مقطوع وP256 تحدي وصول، JP/P98 عدم نص مطابق/صورة لازمة؛ لا تُستنتج منها عدم الإجابة في الأصل. Weak Shinro **هوية معلقة** تحتاج اسمًا أصليًا/معرفًا قبل البحث الشخصي.

## قرار نطاق البحث التالي

تُغلق دورة التفريع الحالية بوصفها **مقارنة حالات**؛ لا يعاد LN8/LN9 أو قناتا الإيمان/الـavatar دون شاهد جديد، ولا يفتح فصل حرب تالٍ تلقائيًا. تحفظ فجوات الإحياء أعلاه حتى مؤشر يطابق السؤال فعلًا.

**الأولوية المستقلة التالية GAIA-FOLLOW:** ابدأ بالسجل [Gaia](gaia-core.md) وموضع LN10 فصل5 line_5244–5270 المحفوظ؛ لا تعِد عملية التجهيز كدليل جديد. عيّن أولًا موضعًا لاحقًا يذكر Gaia ثم اقرأ سياقه المحدود؛ إن لم يثبت اكتمال التعافي يبقى مجهولًا وتُراجع أولوية شخصية من الفهرس. لا يفترض تطابق أرقام line_N مع أسطر GitHub.

ملفات الأولويات السبع جميعها جزئية، وWeak Shinro مجهولة الهوية؛ ليست هذه المراجعة مستندًا شاملًا لسلوك جميع الشخصيات/القدرات. [فهرس التغطية](../COVERAGE.md) و[الفجوات](../GAPS.md) هما مرجع التقدم.
