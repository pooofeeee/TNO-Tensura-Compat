# السيطرة والإكراه — حالة غلندا

## V10-C4-CTRL

SR10، فصل 4، [line_4032–4042](https://tensurafan.github.io/read/v10#line_4032)، line_4058–4069 وline_4104–4127. ترجمة DasRay/Anna، الطبعة 7، مارس 2023؛ فقرات إلكترونية، لا صفحات مطبوعة.

| طبقة الدليل | النتيجة المحدودة |
|---|---|
| تفسير ريمورو بإرشاد رافائيل | تأثير رغبات مزروعة؛ Unique لدى غلندا يحمي الروح من الفساد الكامل. ليس وصفًا لاختبار كل Unique |
| شهادة الأسيرة | قيد طاعة وخوف من تحطيم الروح إذا اعتُبرت خائنة؛ لا يثبت أن جميع المستدعين في LN مقيدون |
| إجراء ونتيجة سردية | رافائيل يعرض فك القيد، وريمورو يوافق؛ يقرر السرد أنه فُك |
| ما لا يُدمج تلقائيًا | قيد الاستدعاء، تأثير Greed، والخوف من الانتقام ليست أسماء مترادفة مثبتة لآلية واحدة |
| ما بقي | منشئ كل طبقة، علاماتها، تكلفة رفعها وموانعه، مدى/مدة تأثير الرغبة، وهل رفع القيد أزال كل أثر نفسي |

**نموذج استدلال، لا قانون شامل:** يمكن أن يتزامن إكراه خارجي مع رغبة نجاة وحسابات اجتماعية. طلب غلندا للعمل بعد فك القيد لا يبرهن على براءة كل أفعالها أو انتفاء كل استقلالية سابقة.
