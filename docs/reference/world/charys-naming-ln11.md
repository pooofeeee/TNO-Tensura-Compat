## REF137 / V11-CHR-FORM — تغير هيئة وإرادة وحد معرفة

**المواضع:** [L1031–1067](https://github.com/tensurafan/tensurafan.github.io/blob/97b06b7659fcfe30a3ec396a5c2c8fa0962bbe00/ln/sources/Volume%2011/Chapter%202#L1031)، مع L933–967 للسياق السابق.

**المشاهدة/الكلام:** يصف ريمورو عودة البنية من هيئة أنثوية إلى هيئة ذكورية مع بقاء ألوان الشعر. يقر Veldora بتدخله في الهيئة الأولى. يفسر الراوي التحول الثاني باحتمال أثر إرادة إفريت؛ ويقول Charys إن إرادته غلبت، ثم يعرض إمكان الرجوع للهيئة السابقة. يسمح Veldora ببقاء الشكل الذي يفضله.
