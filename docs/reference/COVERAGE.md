# فهرس التغطية

تاريخ الفحص: 2026-10-30. النطاق المستهدف شامل مستقبلًا، لكن مقام التغطية الحالي هو **الأولويات السبع المطلوبة** فقط. لا نسبة اكتمال للسلسلة، ولا ملف مكتمل للشخصية.

الحالات: **غير مقروء**؛ **هوية معلقة**؛ **مشاهد جزئية**؛ **مرحلة مراجعة** بعد تدقيق مشاهد مؤيدة/مضادة؛ **مكتمل ضمن نطاق** بعد تحديد المجلدات والفصول وتدقيق جميع الحقول. لا سجل بلغ الحالتين الأخيرتين.
