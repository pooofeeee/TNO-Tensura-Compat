# فهرس التغطية

**المنهج الحالي:** [الخطة المتسلسلة](sequential/README.md) و[الدفتر](sequential/COVERAGE.md) و[النسخ](sequential/SOURCES.md) و[الفهرس](sequential/EXTRACTION_INDEX.md). اكتملت قراءة LN1/F01 P1–P267، كل صفحات هذه النسخة فقط. [الدفعة الخامسة عشرة](sequential/batches/SEQ-LN01-0015.md) تغلق P232–P267 مع البطاقات والقصة الجانبية وكلمة المؤلف. التالي LN2 من بدايته عبر مسار مسموح؛ مسار F02 المقيد لا يعاد. لا ترقيم مطبوع أو اكتمال للمرجع العام.

**المصفوفات التاريخية التالية تخص الأولويات السبع والشواهد الجزئية فقط؛ ليست مقام التغطية المتسلسلة الجديدة لجميع نصوص LN أو تعداد كل شخصياتها.**

تاريخ الفحص: 2026-10-30. النطاق المستهدف شامل مستقبلًا، لكن مقام التغطية الحالي هو **الأولويات السبع المطلوبة** فقط. لا نسبة اكتمال للسلسلة، ولا ملف مكتمل للشخصية.
