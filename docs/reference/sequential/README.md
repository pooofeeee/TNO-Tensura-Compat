## إجراء كل دفعة

1. تثبيت المصدر والنسخة واللغة/المترجم وموضع البداية. إذا تغيرت النسخة لا تنقل ترقيمها أو تقدمها تلقائيًا.
2. قراءة كامل النطاق المتصل، بما فيه العناوين/التعليقات على الرسوم عند وجودها. البحث عن كلمة/ظهور مقتطف أو تحميل ملف ليس قراءة؛ الرسم بلا نص سردي لا يثبت قواعد قدرات.
3. تسجيل الصفحة المطبوعة إن ظهرت فعلًا، وإلا null. في Slime Reader تثبت الفصول/الفقرات بمرجع مستقر؛ في المصدر العام المثبت يمكن استعمال أسطر Markdown عند commit `97b06b7659fcfe30a3ec396a5c2c8fa0962bbe00` مع التصريح بأنها ليست صفحات. لا ترقيم صفحات مخترع.
4. استخراج موجز أصلي: الشخصية/الهوية والمرحلة؛ القول/الفعل/التقرير/التوقع؛ المهارة/الفن/السحر/المادة؛ شرط/سبب/آلية/نتيجة/مورد/حد/مقاومة/تعلم/تطور، وما لم يذكر. لا يلزم ملء كل حقل بفكرة جديدة إذا لم يقدم النص دليلًا.
5. ربط التكرار بسجل قائم بعد قراءة الصفحة فعلًا، وعدم نسخه كدليل جديد. حفظ تناقض النسخ/المراحل واللبس والمجهول؛ لا تلخيص يحل محل الرواية أو اقتباسات طويلة.
6. تحديث [دفتر التغطية](COVERAGE.md) واستخراج الدفعة والفهارس والحالة، ثم نشر وثائق الفرع والتحقق من الرأس/المحتوى. حفظ آخر موضع واضح دون ادعاء اكتمال جرد الشخصيات أو المهارات.
