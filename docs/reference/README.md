آخر تحديث: 2026-10-30. مدخل واحد للمرجع الدائم المطلوب للمنفذ. **التغطية أولية وجزئية**؛ إنشاء ملف لا يعني إنجاز الشخصية. استمرارية LN هي الأساس، وInfinity وأعمال إصلاح المودباك مستقلة.

ابدأ بـ[التغطية](COVERAGE.md)، ثم [المصادر](SOURCES.md) و[الفجوات](GAPS.md). استخدم ملف الشخصية المحدد زمنيًا، واتبع روابط القدرة والقانون والدليل. السجلات المعتمدة السابقة محفوظة في [أدلة التجسد](../TNO_EMBODIMENT_EVIDENCE.md).

ابدأ أيضًا بـ[تدقيق الجولة وحدود إغلاقها](ROUND_AUDIT.md) و[خطة التغطية](CHARACTER_BATCH_PLAN.md). أُغلقت جولة مقارنة الحالات المقروءة عندe56c5a5 بعد التحقق. أحدث حزمة شخصية: [Masayuki، مسؤولية الحرب والخيانة والحماية LN13–14](characters/masayuki-war-betrayal-ln13-14.md)، REF116–118، مع فصل أفعاله عن التحقيق وشكوك الهوية. ## قواعد القراءة والتنفيذ

- كل نتيجة تُربط برقم سجل ونسخة ومجلد وفصل وموضع وسياق المتكلم. مثبتات line في Slime Reader معرفات فقرات إلكترونية وليست أرقام صفحات؛ لا تنقلها إلى طبعة أخرى.
- «صريح» يشمل تصريح شخصية مع نسبته إليها؛ ليس كل تصريح حقيقة موضوعية. احتفظ بفرق المعرفة بين الشخصيات، وبالتراجع أو التفنيد اللاحق.
- «استنتاج» تحليل الباحث، و«مجهول» نقص محدد. المقترح التنفيذي، إن كُتب لاحقًا، له حقل مستقل ولا يصبح canon.
- لا تُعمّم مرحلة على عمر الشخصية كله، ولا نجاحًا على كل الخصوم. لا يثبت EP أو تصنيف المود وحده نتيجة مواجهة.
- كل سجل يحدد ما يصلح للاستناد إليه وما لا يكفي للتنفيذ. مرجع مشهد موثق يمكنه تقييد السلوك، لكنه لا يمنح أرقام تكلفة أو مناعة مطلقة لم يثبتها.
- الأنمي والمانغا وWN والألعاب وأقوال المؤلف والترجمات المختلفة مسارات منفصلة. لا توجد مقارنة بينها في الدفعات الحالية.
- لا نصوص طويلة أو ملفات روايات كاملة. لا تثبيت أدوات أو شراء/اشتراك. لا كود أو main أو سيرفر أو مراسلة المنفذ.

## شكل السجل التفصيلي

**الشخصية:** هوية/أسماء بديلة مثبتة؛ مرحلة زمنية؛ دوافع وقيم؛ معرفة وحدودها؛ علاقات؛ قرار وسببه؛ الخطر والتفاوض والقتال؛ خطأ/قيد؛ مشاهد مؤيدة أو مضادة؛ ما لم يُقرأ بعد.

**القدرة:** صاحب ومرحلة؛ آلية؛ تفعيل؛ مورد وتكلفة؛ مدى/مدة؛ حدود ومقاومات؛ تداخلات؛ تطور؛ شاهد نجاح وفشل؛ جاهزية التنفيذ. غياب المعلومة لا يساوي انعدام الشرط.
